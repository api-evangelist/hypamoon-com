Hypamoon provides a flexible, AI‑enhanced platform that lets teams build and run collaborative applications without writing code. Users can create custom sites, apps, agents, and data workflows that integrate with popular AI assistants like Claude, ChatGPT, and Copilot. The service includes built‑in payment processing, communications tools, domain management, and knowledge‑base features, all accessible through a unified interface. Hypamoon aims to streamline digital workspaces, enabling rapid deployment of low‑code solutions for businesses of any size.

**Areas:** AI · Collaboration · Productivity · Platform · Low-code

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Hypamoon: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
